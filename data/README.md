# data/

No experimental datasets are bundled in this package. Digitized/measured
values used for parameter provenance (e.g. Table S1's antigen decay
kinetics, Fig. 3F's Tfh-count fit targets) are cited by location in
`docs/equations.md` and `docs/parameter_table.md` rather than duplicated
here, to avoid redistributing the source papers' data without attribution
review.
